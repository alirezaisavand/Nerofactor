# Bell-R1 standalone completion

Use the previously frozen Bell-R1 scene and recipe byte for byte. The admitted
heterogeneous Bell reference, corrected visibility image, seed, initialized
material, neighborhood sequence, distance weights, coefficient 0.05 and
pseudo-Huber delta 0.008516476041898608 are fixed. The launcher verifies
the saved calibration identity. No calibration fit is performed.

Donut-R1 stopped before update 2,569 and remains incomplete. Bell-R1 had zero
updates in that batch. The fresh launch verifies the prior receipt, freeze,
approval and saved container ID. Before any new training starts, the Docker
daemon must return no matching container by full ID or by its exact owner
label, including stopped containers. This checks host container cleanup and
records it separately from the prior Python receipt. The launcher leaves the
failed batch and other containers untouched. [Prior failure evidence](../results/robust_tensor_q_v1/README.md)

If the existing zero/near-zero chart-orientation guard fires, the failure
receipt records the retained forward data directly from the exception frames.
It records the actual raw vector and norm, native point, both original chart
widths, and the squared-width gap divided by their squared sum for the first
16 bad rows, with the total count and configured threshold. For a surface
pair it also records the pair ID and endpoint side. Missing exception context
is reported as unavailable. The unchanged exception aborts the pending
operation. The observer runs only on that failure and adds zero render,
predictor or optimizer calls.

Run one fresh Bell history with 10,000 Adam returns and save existing maps
and checkpoints every 2,000 updates. Keep the frozen maxima of 12,480 shader
calls, 9,683,263,488 shadow rays, 1,280,000 sampled surface pairs, 36 diagnostic
reverse sweeps and 12 boundary predictor calls covering 29,688 point
evaluations. Use GPU 0 on A100, four CPU threads, 64 GiB RAM without swap,
128 PIDs, the 25% CUDA allocator limit and 8 GiB owned outputs. The outer
foreground limit is 3,780 seconds with 30 seconds of grace. The inherited
3,600-second Docker arm and 3,540-second inner limits remain in force.
Run non-root, networkless, with read-only source, root and inputs.

Use the saved-array evaluator at update 10,000 against B2 and D2. Retain the
signed width jumps, projected Q jumps, boundary transitions, smooth-interior
and isotropic cohorts, low-coverage errors, common-subset orientation,
illumination and RGB metrics, along with attenuation and gradient scales.
On failure, preserve partials and stop without retry or extension.
Donut-R1 and further robust variants are outside this approval.
