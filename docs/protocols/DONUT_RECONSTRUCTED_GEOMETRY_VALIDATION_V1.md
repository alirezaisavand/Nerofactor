## Evaluation correspondence

For each reconstructed foreground hit, query the nearest point on the admissible oracle triangle surface with an exact point-to-triangle closest-point calculation after AABB pruning. Search all intersecting triangle AABBs within a radius of `0.005` native units. Save triangle ID, barycentric coordinates and the distance, and apply the same search back to the reconstructed mesh from the oracle point. Keep a material correspondence only if both searches succeed, the reverse point returns within `0.005` native units of the original reconstructed hit, and the signed normal angle is at most 30°. These are predeclared engineering filters for transfer, chosen from a scene-space distance near one cell of the pinned G default extraction grid (`2/511`), and a finite shared normal hemisphere margin. They do not establish mesh accuracy or imply that the historical mesh used that grid.

Require that the camera can see the transferred oracle point. Reuse the recorded first hit on coincident rays. Otherwise issue one ray per candidate toward that point on the oracle and require the first depth to agree within `2e-4` native units. Check material side using the admitted analytic region definition. Treat a candidate as ambiguous if tied projections within `2e-4` of the nearest distance land on different material sides, or if the same-ray oracle hit and transferred point lie on different sides. Record oracle-hidden, failed round trip, excessive displacement, normal disagreement, boundary-side ambiguity, and unresolved source-face assignments separately. Use a fixed ordering of validity reasons for totals and also retain individual reason masks. Report corresponding fractions for each primary-mask class and split. No fitted labels or RGB residuals enter the geometric search.

For valid transfers, use the unchanged analytic field at the oracle location and its original smooth shading normal. Save the transferred labels as new evaluation data. Rotate the oracle Q into the reconstructed tangent plane by the shortest normal-aligning rotation and check eigenvalue preservation. Report world-Q shift, any numerical change in sorted widths and director angle modulo sign, with the admitted anisotropy-gap eligibility rule. On common hits, separate the change from sampling a different surface point from the change due solely to transporting the frame. No RGB or BRDF evaluation is part of this gate. If admitted, the next separate experiment renders the fixed oracle material on each mesh under the same L2 illumination and independent integration, with incident visibility recomputed for each mesh. That will measure the geometry-induced RGB floor before any recovery comparison.
