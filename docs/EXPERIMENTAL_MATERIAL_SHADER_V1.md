# 3C-0 experimental known-input material shader v1

This milestone implements a differentiable analytical shader and designs a
known-material recovery benchmark. **No recovery, optimization, dataset
production, training, GPU execution or old experiment was run.** CPU fixture
success is forward/gradient evidence, not inverse-recovery or physical-validity
evidence. The benchmark remains a proposal requiring execution approval.

## Implementation and identities

[material_shader_v1.py](../experiments/material_shader_v1.py) provides
`MaterialShaderV1(variant, decoder, diffuse_samples=512, specular_samples=1024)`.
It reuses the accepted hash-admitted pure A/B3 methods in plain Python objects,
without importing scientific modules or constructing neural networks. It has
no optimizer, training loss, artifact loader or filesystem writer.
The sample defaults are the original **bell** settings; the generic original A
shader default was 256 specular samples. Tiny tests explicitly use 32/32.

| Estimator identity | Specular denominator | Diffuse radial heights |
| --- | --- | --- |
| A0 | Original max(Nvalid,1) | Original remapped elevation |
| A1 | Total M, approved B3 | z=j/N, approved B3 cosine map |
| A2 | Total M | z=(j+.5)/N, midpoint cosine map |

Decoder identity is independently `original` or `atan2`. The immutable reference
is **(A0, original)**. (A0, atan2) is an explicit decoder-only experimental
factor, not original A. Every result records both choices, counts, radial rule,
actual height SHA-256 and original-source identities. A2's original-source
height metadata describes the original construction; its separate actual-height
hash identifies the midpoint pattern. No variant silently changes sample counts.

The underlying A methods preserve:

- Beckmann slope widths mx,my in [.04,1], with no extra roughness squaring.
- d=albedo*(1-metallic), F0=.04*(1-metallic)+metallic*albedo.
- Original a=0 Kurt specular weights, Fresnel reconstruction and masking;
  no Smith G, new energy allocation or BRDF replacement.
- Original spherical Beckmann inversion, clamps, float casts, PDF and basis.
- Stored golden-angle azimuths and random-azimuth operation order.
- Legacy returned f_s_sum/L_spec and original linear-to-sRGB function.

A1 reuses 3B-2 B3; A2 changes only the underlying diffuse heights by half a bin.
Cosine coefficients are sqrt(z), sqrt(1-z), without the original remapped
sampler's 1e-7 perturbations. A0 retains that original perturbation unchanged.

`shade(...)` takes explicit CPU float32 tensors:

| Input | Shape / meaning |
| --- | --- |
| positions, normals, views | [P,3]; known positions, unit outward normal and unit surface-to-view direction |
| mx, my, metallic | [P,1]; physical parameters, not head logits |
| albedo | [P,3], RGB in [0,1] |
| encoding | [P,2], raw double-angle vector normalized with the original head convention |
| RandomInputs(u,v,azimuth) | [P,M], [P,M], [P,1,1], fixed uniforms in [0,1) |
| illumination(positions,directions) | [P,S,3] -> nonnegative linear RGB[P,S,3] |

Positions/directions are supplied in the same declared world frame. The callback
replaces learned lighting/visibility with known illumination. It must use graph-
connected Torch operations for direction-dependent material derivatives; converting
its directions to NumPy/detaching them invalidates that derivative contract.
Constant lighting legitimately has no directional derivative.
This API does not implement BVH visibility, indirect lighting, learned fields,
geometry reconstruction or native renderer parity.

Two explicit specular draws are consumed in both evaluation and training modes.
`is_train=True` additionally consumes the original one azimuth shift per point;
False uses no diffuse shift. The original A method order remains specular then
diffuse. Draws are injected in a per-call function namespace, with no global
Torch patch, seed or RNG consumption. Caller-supplied tensors are not detached
from material computation. No random numbers are generated by the shader.

Validation rejects wrong shape/type/device, nonfinite values, invalid parameters,
nonunit normals/views, lower-hemisphere views and invalid uniforms. It does not
repair inputs. Outputs include linear/sRGB radiance, component radiance, samples,
TBN/PDF, encoding status, frame-orthonormality flag and legacy diagnostics.
Linear RGB is the benchmark quantity; no display clipping is applied.

Minimal usage shape (API illustration, not a recovery command):

```python
import torch
from experiments.material_shader_v1 import MaterialShaderV1, RandomInputs

shader = MaterialShaderV1('A2', 'atan2')
# All tensors must be explicit CPU float32. Obtain private u/v/azimuth before
# the call; preserve/hash them in any future separately authorized experiment.
# result = shader.shade(positions, normals, views, mx, my, albedo, metallic,
#                       encoding, known_illumination, RandomInputs(u, v, azimuth))
# result['linear_rgb'] retains the material autograd graph.
```

## Decoder and gradient findings

The experimental decoder normalizes r and uses theta=.5*atan2(ry,rx), then
cos(theta), sin(theta), with the original rotated-basis formula. Only the
coefficients used by that rotation are replaced; source sampling remains intact.
At (-1,0), the corrected T/B are unit and perpendicular, whereas original A
still yields norm approximately .001. Valid regular encodings produce right-
handed orthonormal frames on the tested flat and curved normals.

Zero means both components exactly zero; near-zero means nonzero encoding with
norm below **1e-6**. The corrected decoder rejects both, as well as norm overflow,
with an explicit no-fallback error. Original mode preserves its original
normalization/degeneracy and reports invalid encoding/frame status separately.
An encoding can be valid while its original decoded frame is degenerate.

Proposed future policy, **not implemented**: parameterize a scalar theta for
constant-material recovery and encode (cos(2theta),sin(2theta)), avoiding radial
zero encodings. The proposed fallback for a future learned-field training runner
is fail-stop: reject the entire pending update, preserve the invalid point/input
identities and terminate before optimizer.step. No silent point removal, new
draw, previous-angle substitution or theta=0 assignment is proposed. The current
decoder raises an error; update control is not implemented here. This training
policy still requires approval; silently choosing theta=0 is not scientifically neutral.
No differentiability at zero or global tangent-field continuity is claimed.

atan2 has a branch cut at the negative axis. Its half-angle frame changes sign
across the cut; the physical Beckmann distribution is invariant to that sign,
but a finite fixed sampling pattern need not produce identical estimates.
Thus neither a globally continuous frame nor pathwise finite-sample continuity
at the branch cut follows from the physical theta-modulo-pi symmetry.
Gradients are checked away from zero, branch cuts, clamps, basis switches and
reflection-mask changes. The original sampler's rejected-sample mask is discrete;
pathwise derivatives there are not a proof of an unbiased full integral gradient.

For all six estimator/decoder combinations, the tiny regular fixture has finite,
nonzero derivatives for mx,my, three albedo channels, metallic and both encoding
components. Central finite differences at h=1e-3 and 5e-4 satisfy predeclared
rtol .03 / atol 2e-4 under float32 source arithmetic. All 32 specular draws stay
accepted, verifying a fixed local mask. The radial encoding derivative vanishes
within 2e-6 as expected from normalization. These are bounded local derivative
checks, not an optimizer convergence demonstration.

A2 integrates the simple cosine-light moment L=ci^2 without A1's left-endpoint
error: midpoint mean(z)=1/2 exactly in real arithmetic. For L=ci^4, midpoint
mean(z^2)=1/3-1/(12*N^2), so a finite O(N^-2) bias remains. N=32 tests compare
both moments to these formulas within float32 roundoff, without changing counts
or asserting exact integration for arbitrary illumination.

## Energy and regularizer consistency

The source locations are field.py compute_radiance, compute_spec_loss and
anisotropic_regularization; renderer.py _init_shader/train_step; and
network/loss.py MaterialRegLoss. Original bell YAML is read-only.

For unit incident illumination, write C_j=F_j*max(ci_j,0)/max(ch_j,1e-6)
and I_j=1(ci_j>0). The original f_s_sum is
sum(I_j*C_j)/max(Nvalid,1). A1/A2 specular radiance uses sum(I_j*C_j)/M,
but **f_s_sum remains conditional**. Under general illumination, radiance
includes each L_j, whereas either reflectance proxy assumes unit illumination.
Changing radiance normalization therefore does not automatically make the
original energy regularizer consistent with the corrected radiance estimator.

| Original quantity / coefficient | Actual effective behavior |
| --- | --- |
| f_s_sum | Conditional unit-light proxy; retains accepted-count normalization in every variant |
| Corrected read-only proxy | Unconditional sum(I*C)/M; separately returned, never substituted into a loss |
| Energy penalty | .05 * mean_points(sum_RGB(relu(d+f_s_sum-1))) for bell's effective shader config |
| L_spec | softmax(D.detach()/1) over all M samples, then L_spec_RGB=d_RGB*sum_valid(softmax)/(3*max(Nvalid,1)) |
| Specular penalty | .05 * mean_points(sum_RGB(L_spec)) |
| Gate | Both penalties are inside reg_change, and require renderer reg_mat plus their own enabled flags |
| Shader defaults | reg_change=True, reg_lambda1=.05, energy/spec flags True, each coefficient .05 |
| Bell top-level declarations | energy/spec coefficients .01; not forwarded into shader_cfg, so do not take effect there |
| Bell shader_cfg | diffuse512/specular1024, light settings; no energy/spec coefficient override |
| Renderer diffuse-light penalty | Separate RGB-whiteness penalty, coefficient .1; not an energy integral constraint |
| Loss wrapper | MaterialRegLoss forwards existing loss_mat_reg/loss_diffuse_light, without a new coefficient |

The shader defaults merge only with shader_cfg (+renderer is_real). Top-level
settings must not be moved into that scope silently. The spatial material
regularizer also remains original, including its unusual orientation coefficient
schedule. This milestone does not evaluate or redesign it.

Because softmax sums to 1 before masking, L_spec scales approximately as 1/M
when accepted fraction is stable; at full acceptance it is exactly d_RGB/(3*M).
For bell M=1024, sum_RGB(L_spec)=mean_RGB(d)/1024. It is not a count-invariant
physical BRDF energy integral. D.detach and Boolean masks mean this term has no
local direct mx/my/orientation derivative while the mask stays fixed. It still
has albedo/metallic derivatives. The new test verifies this detach behavior and
its full-acceptance scaling rather than silently removing detach or changing M.

[material_recovery_metrics_v1.py](../experiments/material_recovery_metrics_v1.py)
implements read-only energy diagnostics: conditional proxy, unconditional proxy,
and independently integrated diffuse/specular/total directional energy. Its
float64 Cartesian hemisphere integral uses explicit caller-provided positive
quadrature weights, not source sampler weights. Two explicit grids are compared;
failed convergence leaves bias comparisons unresolved, with no adaptive retry.
The tiny new fixture uses only 16x32 and 32x64 grids at one broad-lobe case.
No earlier 3B experiment was rerun. A proxy/integral match is not a conservation
claim; the underlying a=0 material law remains capable of reflectance above one.

Recommendations requiring review:

1. For initial known-material recovery, propose a data-only linear-radiance
   objective with known lighting and no spatial/energy/specular priors. This
   measures parameter recovery without confounding prior effects; no loss is
   applied by this implementation.
2. If a future experimental training variant retains an energy prior, give its
   reflectance estimate an explicit unconditional identity, study estimator
   variance and ReLU bias, and compare it to independent integration. Do not
   substitute this output into original training automatically.
3. Study L_spec's intended purpose, detach and 1/M scaling separately before
   any reweighting/replacement. Preserve it as a named historical baseline.
4. Energy-conserving model redesign is a different scientific proposal; neither
   midpoint sampling nor normalization justifies claiming it has been solved.

## Gauge-invariant benchmark metrics

The metrics module implements Q=R(theta)diag(mx^2,my^2)R(theta)^T, relative and
absolute Frobenius error, sorted-axis absolute errors and major-axis angular
error modulo pi. The convention is coordinates in the declared unrotated T/B
frame, not world XYZ. Swapping widths plus theta+pi/2 leaves Q unchanged.
Physical kernel and actual corrected-frame tensor tests verify both that gauge
and theta+pi periodicity. Isotropic physical kernels are orientation invariant.
These equivalences apply to the distribution, not identical fixed-stream draws.

Orientation is scored only when both truth and prediction have relative squared-
width gap |mx^2-my^2|/(mx^2+my^2) >= .1. Otherwise the metric is null with a
reason, never zero error. Q and sorted-axis errors remain reported. A collapsed
prediction against anisotropic truth must count as missing orientation and bad
Q recovery, rather than being excluded as a successful orientation estimate.
See [the benchmark protocol](protocols/KNOWN_MATERIAL_RECOVERY_V1.md) for all
other metrics, identifiability gates, proposed scenes/splits/budgets and the
first experiment, which has not been executed.
