## External baseline decision

The official NeRO synthetic-scene revision exposes the required stage and accepts the acquisition through separable interfaces. The adapter supplies saved oracle positions, smooth normals, outgoing directions, and an incident-light callback. It retains the upstream visibility routing and original shader. The identical corrected BVH and miss criterion make visibility consistent with the project's native renderers. Evaluation records upstream linear RGB before its display transfer and shares the Gate 6 independent unseen-light reference. Stock end-to-end NeRO also learns geometry and light. Label the new comparison **NeRO Stage II, oracle geometry and known incident light**. The official upstream tree is pinned by public ref and verified source hashes. No historical NeRO-labeled mesh, checkpoint, or result enters this test. [Official revision](https://github.com/liuyuan-pal/NeRO/tree/89166a96ea81141dfeec5ba0fc541ccaec92aae4) · [Source manifest](nero-source.json)

NeRO uses a scalar GGX alpha in [0.04², 1] with a Schlick geometry term. Its native GGX distribution uses alpha², while the project's Q contains squared directional Beckmann widths. K1 and Final-Ambient use anisotropic Beckmann widths and the corrected additive Kurt specialization. Match observations, visibility, light, exposure, update count, batch size and training rays. Keep each recipe's solver and priors. NeRO's native sRGB loss uses the upstream, unclipped transfer of the same underlying linear target. All reported image metrics are linear. Image differences compare complete fixed-acquisition recipes on a Kurt-generated target. NeRO cannot represent oriented anisotropy. Compare linear base color and metallic as model-dependent estimates. Preserve native NeRO roughness descriptively and leave Beckmann width, orientation and Q metrics unavailable for NeRO. [Official NeRO shader](https://github.com/liuyuan-pal/NeRO/blob/89166a96ea81141dfeec5ba0fc541ccaec92aae4/network/field.py) · [Protocol](../../protocols/DONUT_NERO_GATE7_V1.md)

## Separate internal attribution

A new A-original experiment is necessary if the paper attributes the Donut gain quantitatively to changes since the thesis. Frozen A source and the prior audits establish the changes themselves. The archived weak-cue Bell comparison and historical thesis tables involve other acquisitions or recipes. A single future A-original run on the same Donut fitting indices, oracle hits, known light, initialization family, objective, budget and unseen-light evaluation would provide a direct internal comparison against K1. Switch only the original versus corrected native behavior where interfaces permit it. That measures the combined correction effect. Individual sampler or prior attribution would still require separate isolation. This Gate 7 freeze contains only the external fit. [A variants](../../NATIVE_MATERIAL_A_CORRECTIONS_E10.md)
